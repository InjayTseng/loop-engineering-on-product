# Product Backlog — full specs for accepted ideas

> One section per idea that passed the value gate. The idea ledger holds one line per idea for
> dedup; this file holds the spec. Do not read this whole file for dedup — read the ledger.

## Format

```
### [IN_PROGRESS] <title>
- Category: <one of CATEGORIES>  ·  Funnel stage: <stage>  ·  Size: S|M|L
- Brief: research/briefs/<file>.md  ·  PRP: PRPs/<date>-<file>.md (every round; depth by size)
- Hypothesis: <why this moves the stage>
- Change: <the one small localized change>
- Value-critic: impact=? novelty=? effort=?
- Validator verdict: <PASS/PARTIAL/FAIL + date>
```

Status transitions: IN_PROGRESS → COMPLETED (shipped) | FAILED (build/validate gave up, reverted).
