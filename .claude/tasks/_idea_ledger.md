# Idea Ledger — one line per idea ever considered (the loop's only dedup source)

> Rule (from "loop until dry"): the dedup set is EVERYTHING SEEN, not just what was adopted.
> Otherwise rejected ideas resurrect every round and the loop never converges.
>
> Format: `- [STATUS] Idea title — one-line reason (required for REJECTED / LOW_IMPACT / FAILED)`
> Statuses:
> - COMPLETED / IN_PROGRESS / FAILED — mirrored in `_product_backlog.md` (which holds the full spec)
> - REJECTED — proposed in Step 2/3 and declined (by you or by value-critic), with the reason
> - LOW_IMPACT — a research direction judged not worth pursuing, with the reason
>
> Usage: read THIS file for dedup (never the whole backlog — it grows large). Put identifying
> keywords in titles so a string search catches duplicates.
